## RESTful API for market simulation/analysis

Данное приложение позволяет оперировать такими сущностями как пользователи, товары, события продажи.
Также имеется возможность получать аналитические сводки по объектам и выполнять кластеризацию пользователей
на желаемое количество кластеров на основе признаков связанных с историей покупок и информацией о самом пользователе.


Для запуска приложения в корневой директории проекта выполните

```
docker compose up
```

### NOTE
Все желающие могут перебиндить порт 8001 на любой другой отредактировав `/docker-compose.yml`

### Для доступа к документации (после запуска)
```
http://127.0.0.1:8001/docs
```
или
```
http://localhost:8001/docs
```


### Весь функционал доступен по адресу
```
http://127.0.0.1:8001/api/v1/
```
или
```
http://localhost:8001/api/v1/
```

### Примеры использования API можно найти в `/examples.ipynb`
